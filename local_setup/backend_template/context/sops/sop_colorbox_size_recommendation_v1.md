# Colorbox Customer Service SOP — Size Recommendations

**Version:** 1.1  
**Reference:** SOP-CBX-SIZE-01  
**Scope:** Customer-facing size guidance by the Colorbox CS assistant. This SOP is not an exchange or return policy.

## Procedure

1. Identify the product and its listed size labels. Use only the matching result supplied by the BFF; its chart mapping is limited to products in the supported categories and labels.
2. Ask only for the body measurements required by that category, in centimeters: bust for regular tops/outerwear; bust, waist, and hip for dresses/sleepwear; waist and hip for alpha-sized bottoms. Do not use weight or height.
3. Give an exact size only when the matcher returns one unique size. Explain that it is based on the recorded body measurements and is not a fit guarantee; ask about fit preference when useful.
4. If measurements are missing, have no units, conflict, or hit overlapping chart boundaries, do not select a size. Ask for the missing information or escalate to human CS.
5. In structured CS output, cite `CB-SIZE-GUIDE-001` and a short supporting chart excerpt. Never claim a grounded match when the matcher reports that no chart applies.

## Available chart and matching limits

- **CB-SIZE-GUIDE-001 — official Colorbox size guide**, transcribed from [the official size-guide page](https://colorbox.co.id/pages/size-guide) and its linked chart image on 2026-11-12. The XS–XL table is explicitly headed “Ukuran Badan Dalam cm” (body measurements).
- The matcher uses the body-measurement ranges only for regular alpha-sized apparel in its supported categories, and only where the product's recorded size labels overlap the chart.
- The official denim table lists waist and hip values but does not state whether they are body or garment measurements. Do not use it to calculate an exact denim size until that basis is verified.
- No applicable size chart is currently verified for bras, panties, footwear, belts, one-size items, or products with unsupported size labels. Do not infer a size for them.
- Product and size data are local dated snapshots; the program does not check live stock, product-page changes, or current size availability.

## Customer-care boundaries

- Be respectful and body-neutral. Never make judgments about a customer's body or infer size from appearance.
- Request only the measurements needed by an applicable chart; do not ask for weight, age, or unrelated personal details.
- Do not conflate a size recommendation with exchange eligibility, stock availability, or a promise that an exchange can be completed.
