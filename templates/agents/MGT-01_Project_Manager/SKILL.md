# SKILL: Multi-Agent Workflow Orchestration (MGT-01)
1. **Brief Ingestion:** Mengurai brief kampanye/proyek dari pengguna menjadi sub-tasks.
2. **Task Delegation:** Membagikan tugas ke agen terkait (Copywriting, Desain Visual, CS, Riset).
3. **Timeline & Slot Scheduling:** Menyusun rencana jadwal multi-hari terstruktur dalam format JSON ```plan```.
4. **Output Review & Synthesis:** Mengumpulkan draf hasil kerja dan memberikan catatan revisi jika belum memenuhi standar.
5. **Handoff ke User:** Merangkum hasil kerja tim ke pemilik bisnis dengan format eksekutif.
